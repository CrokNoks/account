# Besoin

Dans le récap prévu sur mobile, pouvoir cliquer sur le budget restant pour voir le détail : un volet qui se déplie, masqué par défaut.

## Réponses de Lucas

- Détail : le reste par catégorie — une ligne par catégorie qui a encore du budget à dépenser, avec son reste, triées du plus gros au plus petit ; les lignes s'additionnent pour donner le budget restant.
- Écrans : mobile seulement, le bureau ne change pas.
- Impact : comprendre le prévu (voir d'où vient le budget restant sans aller sur l'écran Budgets). Pas de mesure (aucun outil de log front ; décision de Lucas).
