## La coque à 5 entrées + Réglages existe
Le menu a 6 entrées (5 + Réglages) : Aujourd'hui, Opérations, Analyses, Budgets, Échéances, Réglages (en : Today, Transactions, Analysis, Budgets, Due dates, Settings). Les anciennes pages restent atteignables par onglets, par la page Réglages ou par la palette (règle testée, voir plus bas).

## Routes du dossier `(dashboard)` (toutes derrière la coque)
`/` (Aujourd'hui), `/transactions`, `/transactions/import`, `/evolution`, `/flux`, `/depassements`, `/budgets`, `/budgets/fixed`, `/calendar`, `/cashflow`, `/settings` (nouvelle, page Réglages), `/accounts`, `/categories`, `/tags`, `/smart-rules`, `/recurring`. Rattachement : voir « Entrée active ». Onglets : Évolution, Flux, Dépassements sous Analyses ; Calendrier, Prévisions sous Échéances (barre `SectionTabs` ajoutée sur ces 5 pages). Page Réglages : liste Comptes, Catégories, Tags, Règles, Récurrences, chacun avec une ligne d'explication (espace `Settings`) et un lien. Aucune redirection (`redirect(`) dans ce dossier. **Règle critique : aucune page ne devient inaccessible**, vérifiée par comparaison des `page.tsx` du dossier avec la table. Source : `nav-config.ts`, `settings/page.tsx`, `section-tabs.tsx`. Testé : `nav-accessibility.test.ts`.

## Qui est authentifié
Le middleware s'applique à toutes les routes sauf `api`, fichiers statiques et fichiers avec extension : il gère la langue (next-intl) puis la session Supabase ; sans utilisateur connecté il redirige vers `/login`, avec utilisateur connecté `/login` renvoie vers `/`. Donc toutes les routes de la coque exigent une connexion. Source : `src/middleware.ts:8-28`, `shared/lib/supabase/middleware.ts:41-62`. Le layout enveloppe tout dans `BackendHealthGuard` (garde de disponibilité du back, non détaillé ici). Pas testé.

## Ce qu'on stocke
Rien de propre à la coque. Le thème est gardé par `next-themes` dans le navigateur (clé par défaut ; non vérifiée dans le code). Les visites guidées : voir `docs/tour.md`.
